# GameYob v0.5.12

HuC3 games now retain elapsed seconds between clock updates. Reads or saves less than a minute apart previously discarded those seconds, delaying the game clock. Regression tests cover frequent polling, midnight and year rollover, and backward host-clock changes. Battery save and save-state formats are unchanged. Physical HuC3 cartridge testing is pending.

This DS/DSi release also includes x1.1–x1.6 zoom steps, vertical pan and validation of stored menu selections. Back up saves before replacing the emulator. The Castlevania fast-forward display issue is tracked in [issue #8](https://github.com/GimoXagros/GameYob/issues/8). The ZIP includes the inherited EZ-Flash provenance disclosure in THIRD_PARTY_NOTICES.txt.

HuC3 게임에서 시계를 자주 읽거나 저장할 때 1분 미만의 경과 시간이 사라져 게임 시계가 늦어지는 문제를 수정했습니다. 기존 세이브 형식을 유지합니다. DS·DSi 화면 배율과 세로 위치 조절도 포함합니다.

HuC3 ゲームで時計の読み出しや保存を繰り返すと1分未満の経過時間が失われる問題を修正しました。従来のセーブ形式を維持し、DS・DSi の画面倍率と縦の表示位置も選べます。
