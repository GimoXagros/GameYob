# GameYob v0.5.3-ko release record

## Scope

This release carries the Korean filename and cheat-list support from
`v0.5.2-ko.1` into the current GameYob overhaul. It also includes the native
Nintendo 3DS SGB-border work, DS/DSi NiFi protocol hardening, renderer
corrections, and noise-channel corrections recorded on the repository's
`master` branch.

The release archive contains homebrew executables only. It does not contain
game cartridges, ROM images, or BIOS files.

## Included builds

- `gameyob.nds`: Nintendo DS-compatible header
- `gameyob_dsi.nds`: DSi-aware header (`GYOB`, title ID `00030004`)
- `gameyob.3dsx`: native Nintendo 3DS homebrew

Both `.nds` files use the same emulator core. The DSi file is separately
packaged for launchers that explicitly enter DSi mode; it does not by itself
guarantee a performance improvement.

## Verification

- Portable emulation regression tests pass.
- Nintendo DS and Nintendo DSi targets build in the pinned devkitARM container.
- The native Nintendo 3DS target builds in the pinned devkitARM/libctru
  environment.
- SGB border output was verified in Azahar with
  *Tales of Phantasia: Narikiri Dungeon* (AN6J).
- Final artifact SHA-256 values are recorded in the release archive.

## Remaining work

See the English and Korean TODO lists in the repository
[README](../../README.md#todo). Physical wireless-link validation and the
native 3DS Wi-Fi backend are intentionally deferred.

# GameYob v0.5.3-ko 릴리스 기록

## 범위

이 릴리스는 `v0.5.2-ko.1`의 한국어 파일명·치트 목록 지원을 현재 GameYob
개편판에 반영합니다. 저장소 `master` 브랜치에 기록된 네이티브 Nintendo 3DS
SGB 보더, DS/DSi NiFi 프로토콜 안정화, 렌더러 수정 및 노이즈 채널 수정도
포함합니다.

릴리스 압축 파일에는 홈브루 실행 파일만 들어 있습니다. 게임 카트리지,
ROM 이미지 또는 BIOS 파일은 포함하지 않습니다.

## 포함 빌드

- `gameyob.nds`: Nintendo DS 호환 헤더
- `gameyob_dsi.nds`: DSi용 헤더(`GYOB`, 타이틀 ID `00030004`)
- `gameyob.3dsx`: 네이티브 Nintendo 3DS 홈브루

두 `.nds` 파일은 같은 에뮬레이터 코어를 사용합니다. DSi 파일은 DSi 모드로
진입하는 런처를 위해 별도 패키징되며, 파일 자체가 성능 향상을 보장하지는
않습니다.

## 검증

- 포터블 에뮬레이션 회귀 테스트를 통과했습니다.
- 고정된 devkitARM 컨테이너에서 Nintendo DS 및 Nintendo DSi 대상을
  빌드합니다.
- 고정된 devkitARM/libctru 환경에서 네이티브 Nintendo 3DS 대상을
  빌드합니다.
- *테일즈 오브 판타지아 나리키리 던전* (AN6J)으로 Azahar에서 SGB 보더
  출력을 검증했습니다.
- 최종 산출물의 SHA-256 값은 릴리스 압축 파일에 기록합니다.
