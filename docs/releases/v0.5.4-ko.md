# GameYob v0.5.4-ko release record

## Scope

This unofficial release adds extensible localization, completes the planned
native 3DS custom-border and LAN-link implementation, improves DS audio and
cheat behavior, and applies a performance/safety maintenance pass suitable for
the current 2026 toolchain. It builds on `v0.5.3-ko` and preserves compatible
save, state, and cheat-file conventions.

The release contains redistributable homebrew and support files only. It does
not contain cartridge ROM images or BIOS files.

## Included files

- `gameyob.nds`: Nintendo DS-compatible build
- `gameyob_dsi.nds`: DSi-aware header for launchers that enter DSi mode
- `gameyob.3dsx`: native Nintendo 3DS homebrew
- `gameyob/languages/`: English, Japanese, and Korean in INI, JSON, XML, YAML
- `LICENSE`, `OFL.txt`, `THIRD_PARTY_NOTICES.txt`, and `SHA256SUMS.txt`

## Highlights

- Embedded English/Japanese/Korean menus, external UTF-8 language parser, and
  non-destructive English custom-template generation on settings save
- Unicode/CP949 filenames and cheat lists on DS/DSi/3DS
- Native 3DS UDP LAN host discovery and reliable link protocol with immediate
  offline rejection and bounded no-peer discovery
- Local-link recovery after wireless sessions and native 3DS CGB fast-serial
  timing
- Native 3DS PNG/BMP custom borders and automatic SGB probing
- Independent DS SO1/SO2 mixing and GameShark `0x8x` SRAM writes
- Table CRC32, allocation-free DS packet sends, hashed glyph lookup, and safer
  path/string processing

## Verification policy

Portable tests cover packet encoding, standard CRC32, renderer rules, noise
LFSR, SGB border decoding, all four localization formats, Unicode clipping,
and malformed input rejection. DS, DSi, and 3DSX builds use pinned devkitPro
environments. Final artifact hashes are written to `SHA256SUMS.txt`.

Azahar validation uses the user's lawful local copy of
*Tales of Phantasia: Narikiri Dungeon* (AN6J); no cartridge data is committed or
distributed. Physical multi-system radio tests remain listed in the repository
TODO because they require hardware not supplied by the source repository.

## Final verification

- Core regression suite: passed on GitHub Actions
- Nintendo DS/DSi build: passed on GitHub Actions
- Native 3DSX build: passed on GitHub Actions
- Azahar 2125.1.3: the final 3DSX loaded AN6J, displayed the game-provided
  256x224 SGB border, advanced through the Namco boot and Japanese title
  screens, and rendered the complete embedded Korean menu without external
  language files
- Final 3DSX SHA-256:
  `1978AA3C87DF9358EEEDCB28A4D2DDF2AE0131D46B719298DC383E6DB2FFAA06`

This is emulator validation. The physical-device and multi-system radio
matrix remains explicitly unverified in `README.md`.

# GameYob v0.5.4-ko 릴리스 기록

## 범위

이 비공식 릴리스는 확장 가능한 다국어 기능, 네이티브 3DS 사용자 보더와 LAN
링크, DS 사운드·치트 보완 및 2026년 도구 환경에 맞춘 성능·안전성 개선을
포함합니다. `v0.5.3-ko`를 기반으로 하며 세이브·상태·치트 파일 관례를
호환되게 유지합니다.

릴리스에는 재배포 가능한 홈브루와 지원 파일만 들어 있습니다. 게임 ROM이나
BIOS는 포함하지 않습니다.

## 포함 파일

- `gameyob.nds`: Nintendo DS 호환 빌드
- `gameyob_dsi.nds`: DSi 모드로 진입하는 런처용 DSi 헤더 빌드
- `gameyob.3dsx`: 네이티브 Nintendo 3DS 홈브루
- `gameyob/languages/`: INI·JSON·XML·YAML 영어·일본어·한국어 파일
- `LICENSE`, `OFL.txt`, `THIRD_PARTY_NOTICES.txt`, `SHA256SUMS.txt`

## 검증 방침

영어·일본어·한국어 메뉴는 실행 파일에 내장되며, 설정 저장 시
`gameyobds.ini` 옆에 영어 기본 `gameyob_language.ini`를 기존 파일을
덮어쓰지 않고 생성합니다. 네트워크 주소가 없으면 3DS 링크 메뉴는 즉시
복귀하고, 상대 기기가 없으면 검색을 10초로 제한합니다. 로컬 링크를 시작할
때는 이전 무선 세션과 두 번째 ROM 상태를 정리하며 3DS의 GBC 고속 직렬
통신 타이밍을 적용합니다.

포터블 테스트는 무선 패킷·표준 CRC32, 렌더링 규칙, 노이즈 LFSR, SGB 보더,
네 가지 언어 파일 형식, 유니코드 문자열 경계 및 잘못된 입력 거부를 검사합니다.
DS·DSi·3DSX는 고정된 devkitPro 환경에서 빌드하고 최종 SHA-256은
`SHA256SUMS.txt`에 기록합니다.

Azahar 시험에는 사용자가 보유한 적법한 *테일즈 오브 판타지아 나리키리 던전*
(AN6J) 파일만 사용하며 게임 데이터는 저장소나 릴리스에 포함하지 않습니다.
여러 실기가 필요한 무선 링크 조합은 저장소 TODO에 그대로 기록합니다.
