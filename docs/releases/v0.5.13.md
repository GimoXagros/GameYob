# GameYob v0.5.13

The DS/DSi build uses the public BlocksDS 1.22.2/libnds rumble API for eligible
Slot-2 peripherals. The inherited EZFlash 3-in-1 source and header, direct
register writes and startup reset have been removed from the active tree.
The SDK detects the device and supplies the supported strength range; DSi mode
does not access Slot-2. Launcher, save format, RTC and NiFi are unchanged.

The release ZIP includes both builds, license notices, guides and checksums.
It does not include game ROMs, BIOS or firmware. For installation, keep the
license files with the distribution. A native 3DSX build is not included.

Physical EZFlash 3-in-1, official Rumble Pak, and DS/DSi/3DS mode behavior
have not been verified on hardware for this change.
