# GameYob v0.5.2-ko.1 릴리스 기록

GameYob 공식 v0.5.2 안정판을 기반으로 현대 한국어 파일명과 치트 목록
지원을 보강한 비공식 홈브루 빌드다. 수정 소스는
[`v0.5.2-ko.1`](https://github.com/GimoXagros/GameYob/tree/v0.5.2-ko.1)
태그에 보존되어 있다.

## 변경 사항

- FAT 긴 파일명 변환을 UTF-8 로케일로 초기화
- 파일 선택기에서 완성형 한글 11,172자와 현대 자모 표시
- UTF-8 및 CP949(Windows ANSI) 치트명 표시
- UTF-8 BOM이 붙은 치트 파일 지원
- 한글 ROM명에 연결되는 세이브, 치트, 스테이트 및 프린터 파일 경로 확장
- UTF-8/CP949 문자열을 중간 바이트에서 자르지 않도록 처리
- 확장자 없는 디렉터리 항목의 잘못된 포인터 접근 수정
- 치트명의 `%`를 포맷 문자열로 오인하던 문제 수정

에뮬레이터 메뉴 UI의 한국어 번역은 포함하지 않는다. 현대 한국어 파일,
폴더 및 치트명 표시에 초점을 둔 빌드이며 Galmuri에 없는 역사적 확장 자모
191자는 `?`로 표시된다.

## 배포 파일

- `gameyob.nds`: DS/DS Lite, 3DS의 DS 모드와 대부분의 플래시카드에 권장
- `gameyob_dsi.nds`: DSi 모드 실행을 명시적으로 지원하는 런처용

3DS에서 플래시카드나 DS 모드로 실행한다면 일반판이 가장 호환성이 높다.
DSi판은 실제 DSi 모드로 실행될 때만 의미가 있으며 눈에 띄는 성능 향상을
보장하지 않는다. 플래시카드에서는 DLDI 자동 패치를 활성화해야 한다.

## 검증

- DS 및 DSi 대상 클린 빌드 성공
- 동일 소스 2회 빌드 SHA-256 일치
- `ndstool` Nintendo logo/header/banner CRC 통과
- 완성형 한글 11,172자 비공백 글리프 검사 통과
- CP949 `B0 A1` → Unicode `U+AC00` 매핑 검사 통과

자동 NDS 실행 검증은 테스트 PC에 emucap용 DeSmuME 실행 바이너리가 없어
수행하지 못했다. 실제 기기에서는 한글 파일명의 테스트 ROM과 UTF-8/CP949
치트 파일을 확인하는 것이 좋다.
