# GameYob v0.5.11 release record

## English

This stable DS/DSi release retains the v0.5.10 work and the ROM reload lifecycle stabilization in PR #6. It integrates the SGB-border, printer, and video-diagnostic work from PR #7. The normal binaries do **not** enable the experimental staged renderer, video trace, or HBlank anomaly instrumentation. Nintendo 3DS users may run `gameyob.nds` in DS mode; the launcher decides the actual execution mode. Native 3DSX is not included.

### Changes

- Isolated disposable SGB-border probing from normal game state and preserved fast-forward input handling.
- Hardened Game Boy Printer packet/serial validation, bounded RLE handling, and checked numbered BMP output through a temporary file. Physical paper behavior, multi-copy printing, and exposure/margin rendering are not claimed.
- Retained normal renderer behavior while adding opt-in, separately labeled diagnostic modes for future display investigation.
- Updated the DS launcher to exactly three lines: `GameYob Custom`, `A Gameboy Emulator for DS`, `GimoXagros`. The provided 32-pixel transparent logo is preserved as the source asset and converted to the banner's 16-color/binary-alpha format.
- Updated in-program Version Info to v0.5.11. State format remains version 8; existing saves/settings are not intentionally migrated.

### Verification and limits

Normal, UBSan, ASan/LSan, core SGB/printer/video regression, package/resource checks, and two pinned BlocksDS 1.22.2 clean DS/DSi builds are release gates. The release manifest identifies the exact source, CI runs, and binary/ZIP hashes. Synthetic printer/host tests do not prove every game or SD/flashcard path. The user reports satisfactory overall stability and performance on a Nintendo 3DS in DS mode with DSpico; this is a user report, not an all-games hardware matrix.

Thin white horizontal lines can still occur intermittently in Castlevania Legends while L fast-forward is held. This is [open issue #8](https://github.com/GimoXagros/GameYob/issues/8), not a verified fix. A prior brief whole-screen black flicker has not been re-reported in recent hardware runs, but no general cause-linked renderer correction is claimed. Collect revision, ROM SHA-256 (not the ROM), device/launcher, settings, and reproducible steps for new reports.

### Installation and package

Back up saves, states, settings, and printer BMPs before replacing an older NDS file. The archive contains `gameyob.nds`, `gameyob_dsi.nds`, English/Japanese/Korean guides, editable language examples, license notices, this record, and per-file SHA-256 checksums. It contains no ROM, BIOS, DSP firmware, personal print, or native 3DSX program. Game Boy Printer BMPs are numbered beside the ROM through a temporary `.tmp` file; allow free SD space. Preserve older packages separately; do not overwrite existing prints.

### Source provenance disclosure

The inherited `platform/ds/arm9/source/3in1.cpp` / `3in1.h` code retains an aladdin / EZFlash Group attribution, but an explicit permission statement for that exact inherited fragment has not been located. The [later Dartz150/EZFlash3in1 repository at `602cead`](https://github.com/Dartz150/EZFlash3in1/tree/602ceadfb5d4af28ad6910ff91757b4a851c0321) publishes related code with a [GPL-3.0 license](https://github.com/Dartz150/EZFlash3in1/blob/602ceadfb5d4af28ad6910ff91757b4a851c0321/LICENSE) and EZTeam credits; the [piugba discussion](https://github.com/afska/piugba/issues/27) concerns rumble implementation/testing. These sources show later community sharing and attribution, **not** a proven public-domain grant, unrestricted use, or retroactive license clearance for GameYob's older fragment. The user explicitly chose to retain the existing feature and publish with this unresolved permission disclosed. No new third-party code was copied or relicensed for this release.

## 한국어

v0.5.11 정식 DS/DSi판은 v0.5.10과 PR #6의 ROM 반복 실행 안정화 수정을 유지하고, PR #7의 SGB 보더·프린터·화면 진단 작업을 통합합니다. 일반 배포 NDS에는 실험적 staged 렌더러나 Video/HBlank 계측이 켜져 있지 않습니다. 3DS에서는 `gameyob.nds`를 DS 모드로 사용할 수 있으며 실제 실행 모드는 런처가 결정합니다. 네이티브 3DSX는 포함하지 않습니다.

- SGB 보더의 임시 탐색을 일반 게임 상태와 분리하고 L 배속 처리를 보존했습니다.
- Game Boy Printer 패킷·시리얼·RLE 검사와 임시 파일을 통한 번호형 BMP 출력을 보강했습니다. 실제 종이 동작, 여러 장 인쇄, 여백·노출 표현을 보장하지 않습니다.
- DS 배너를 정확히 `GameYob Custom` / `A Gameboy Emulator for DS` / `GimoXagros` 세 줄로 변경했습니다. 제공된 32픽셀 투명 PNG 원본은 보존하고 DS 배너 포맷으로 변환했습니다.
- Version Info는 v0.5.11이며 상태 파일 형식은 버전 8을 유지합니다. 기존 세이브·상태·설정·인쇄 BMP를 백업한 뒤 설치하십시오.

사용자는 3DS DS 모드+DSpico에서 전반적인 안정성과 성능을 만족스럽다고 보고했습니다. 하지만 모든 게임·기기의 검증이 아니며, Castlevania Legends에서 L 배속 중 얇은 흰 가로줄이 간헐적으로 나오는 문제는 [미해결 이슈 #8](https://github.com/GimoXagros/GameYob/issues/8)로 남습니다. 합성 프린터 시험과 CI 성공도 실제 게임·SD 경로 전체를 증명하지 않습니다. 문제 제보에는 ROM 파일 대신 SHA-256, 빌드 리비전, 기기·런처, 설정과 재현 절차를 보내주십시오.

`3in1.cpp`/`3in1.h`의 기존 aladdin / EZFlash Group 출처 표기는 유지되지만, 해당 오래된 코드 조각에 적용되는 명시적 허락 문서는 확인되지 않았습니다. [후대 EZFlash3in1 저장소의 GPL-3.0 표기](https://github.com/Dartz150/EZFlash3in1/blob/602ceadfb5d4af28ad6910ff91757b4a851c0321/LICENSE)와 [piugba 이슈](https://github.com/afska/piugba/issues/27)는 후대의 공유·구현 논의를 보여줄 뿐, GameYob의 과거 조각을 소급해 자유 이용 가능하게 하는 근거는 아닙니다. 사용자는 이 미확인 권한 상태를 공개하면서 기존 기능을 유지해 배포하기로 선택했습니다. 이번 릴리스에서 제3자 코드를 새로 복사하거나 재라이선스하지 않았습니다.

## 日本語

v0.5.11はDS/DSi向けの安定版です。v0.5.10とPR #6のROM再読込安定化を維持し、PR #7のSGBボーダー・プリンター・画面診断作業を統合します。通常版には実験的な段階的描画やVideo/HBlank計測を含めません。ランチャーがDS/DSiの実際の実行モードを決め、ネイティブ3DSXは同梱しません。

SGBボーダー探索の分離、プリンターパケット/シリアル検証と一時ファイルを使うBMP保存を追加しました。ランチャーの表示は`GameYob Custom`、`A Gameboy Emulator for DS`、`GimoXagros`の3行です。状態形式は8のままなので、更新前にセーブ・ステート・設定・印刷BMPをバックアップしてください。3DSのDSモード+DSpicoで全般的な安定性と性能が良いとのユーザー報告がありますが、全ゲームの確認ではありません。Castlevania LegendsのL早送り中の白い横線は[未解決のissue #8](https://github.com/GimoXagros/GameYob/issues/8)です。

継承した3in1コードの元の許可条件は確認されていません。後年のGPL-3.0表記はGameYobの古いコード片に遡って許可を与える証明ではありません。既存の帰属表示と未確認の状態を残し、新たな第三者コードのコピーや再ライセンスは行っていません。
