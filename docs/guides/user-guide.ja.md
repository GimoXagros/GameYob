# GameYob v0.5.10 ユーザーガイド（日本語）

## 1. ビルドの選択

- `gameyob.nds`: DS、DS Lite、フラッシュカード、Nintendo 3DSのDSモードに推奨します。
- `gameyob_dsi.nds`: DSiモードを明示的に起動するランチャーで使用します。エミュレーター本体は通常NDS版と同じで、速度向上を保証するものではありません。
- Nintendo 3DSでは`gameyob.nds`をDSモードで使用できます。実験的な3DSネイティブ版は本リリースに含めず、[`backup/3dsx`](../../backup/3dsx)にのみ保存しています。

ROMとBIOSは同梱されません。合法的に用意した`.gb`、`.gbc`、`.gbs`をSDカードへコピーして選択してください。コンソール版はSDルートに`gameyobds.ini`を作成するため、書き込み可能な状態が必要です。

## 2. 操作とメニュー

標準設定では十字キー、A/B、Start、Selectをそのまま使用します。DS標準設定ではRでメニュー、Lで早送りです。**設定 → ボタン設定**では、メニュー、メニュー/一時停止、保存、連射、早送り、リセット、ローカルリンクのフォーカス切替などを変更できます。拡大操作は現在DS/DSi版でのみ有効です。

**画面 → タッチメニュー**は既定でOnです。有効中は保存済みの**ゲーム画面**設定を変更せず、メニューとROM/ファイル選択画面を一時的に実際のBottom Touch Screenへ表示します。別の行を1回タップすると選択のみ、選択済みの実行項目をもう1回タップすると実行します。選択済みの値項目では左半分/右半分で前/次の値へ進みます。タイトル行の左/右はカテゴリ移動、中央はメニューを閉じます。ファイル選択も1回目で選択、2回目で開き、矢印領域でスクロール、下端の終了行はYと同じです。物理ボタンは引き続き使用できます。ゲーム中の設定可能な**Touch**割り当ては別機能で、UI外では従来どおり動作します。Nintendo 3DSのDSモードで`gameyob.nds`を使う場合も同じです。

## 3. ROMメニュー、セーブ、サスペンド

- **ステートスロット**で0～9を選び、**ステート保存/読込/削除**を実行します。
- **リセット**は現在のカートリッジを再起動し、**サスペンド**は再開用ステートを保存します。
- **終了**は通常保存します。**保存せず終了**は最後の保存を意図的に省略します。**ランチャーへ終了**はDS/3DSランチャーへ戻ります。
- バッテリーセーブは`.sav`、2台目のローカルGame Boyは`.sa2`、ステートは`.ys0`～`.ys9`、サスペンドは`.yss`です。
- DS版の**自動保存**はSRAMのバックグラウンド書き込みを制御します。電源やSDカードを外す前に通常終了してください。

## 4. 設定と言語

- **言語**で内蔵の英語、日本語、韓国語、またはCustomを選ぶと即時反映されます。
- Custom選択後、**言語ファイル選択**でUTF-8のINI、JSON、XML、YAML、YMLを読み込みます。
- **設定保存**は`gameyobds.ini`を保存し、同じ場所に存在しない場合だけ英語の`gameyob_language.ini`を作成します。既存テンプレートは上書きしません。
- **コンソール出力**はOff、時計、FPS+時計、デバッグログを選択します。
- **GBプリンター**はプリンターエミュレーションを有効にします。成功した印刷ジョブはROMと同じ場所に連番BMPとして保存されます。試験や大切な画像の印刷前にSDカードをバックアップしてください。対応範囲ではジョブごとに別画像を作成します。複数枚印刷と、BMP出力への用紙余白・露光の反映には対応していません。
- DS専用設定は**振動パック**、対応DSiの**GBカメラ**（内側/外側）、**自動保存**です。

外部言語ファイルの仕様と例は[言語ファイルガイド](../../languages/README.md)を参照してください。

## 5. チート

ROMと同じ場所に同じベース名で配置します。`Game.gbc`なら`Game.cht`です。UTF-8を推奨し、韓国語の旧リストはCP949も読み込めます。各行にはGame Genieコード（`AAA-BBB`または`AAA-BBB-CCC`）か8桁GameSharkコード、有効フラグ、表示名を記述します。**設定 → チート管理**で切り替え、**設定保存**で選択を保存します。

## 6. 表示、ボーダー、Game Boyモード

- **ゲーム画面**は上/下画面、**単一画面**は未使用画面の非表示を選択します。
- DS/DSi版には**拡大**と**拡大フィルター**があります。
- **SGBボーダー**は対応カートリッジの枠を表示します。**カスタムボーダー/ボーダー選択**はBMPを読み込みます。
- DS/DSi版の**GBC BIOSを選択**では、正確に0x900バイトの`.bin`を指定できます。選択後はゲームをリセットまたは再読込し、使用する**GBC BIOS**モードを選びます。**設定を保存**すると絶対パスが`gameyobds.ini`の`biosfile`へ記録されます。未指定の場合は従来どおり現在の作業フォルダーの`gbc_bios.bin`を検索します。BIOSは任意で、配布物には含まれません。
- **GBCモード**はOff、If Needed（CGB専用ヘッダー`0xC0`）、On（CGB対応ヘッダー`0x80`/`0xC0`）です。Onでも白黒専用ヘッダーを強制CGBにはしません。**SGBモード**はOff、GBC優先、SGB優先です。**GBA検出**は起動時の機種識別フラグであり、高速化設定ではありません。変更後はリセットまたはROMを再読込してください。

## 7. プレリリース候補の確認事項

以下は候補ビルドの確認中の動作であり、プレリリース公開済み、または全対応ゲームで検証済みという意味ではありません。SGBボーダーの抽出では通常プレイ前に一時的な起動処理が行われる場合があります。セーブをバックアップし、短い起動待ちだけでフリーズと判断しないでください。標準DS割り当ての早送りはLボタンです。**GBA検出**は早送りとは無関係です。ユーザー報告ではSGB Borders Onで速度低下と早送りの問題があり、現在は回避策としてOffを使用しています。当時のCustom Border設定は不明です。SGBボーダー、拡大表示、早送りを組み合わせた性能は検証中です。

プリンター出力を使うには、対応ゲームの起動前に**設定 → GB Printer → On**を選択してください。ユーザー報告では、この設定がOnでもNintendo 3DSのDSモード+DSpicoでTalesのメインメニューからプリンター用サブメニューのPrintを選ぶと進行しませんでした。このゲーム手順は候補ビルドで実機確認されていません。BMPはROMの保存名に番号を付けてROMと同じ場所へ保存します（例：`game-0.bmp`）。完成画像を保存先へ置き換える前に一時`.tmp`ファイルを使います。SDカードの空き容量を確保し、既存ファイルを保護してください。実機の用紙動作は再現せず、1枚の出力のみ対応し、余白や露光は画像に反映されません。BMPが作成されたか確認してください。プリンター診断ログを確認するには**コンソール出力 → Debug**を選択します。画面上のエラー表示は保証されません。候補`a0846aae`では、パーサー/BMP合成試験、リンク相手の保留転送、640バイトを超える有効RLE展開を含むGB/CGB本番シリアル経路のホストテストが通過し、同一ソースのCIも通過しました。ユーザーのゲーム、SD/FATパス、実機は未確認です。不具合報告にはビルドリビジョン、ROMのSHA-256、プリンター設定、拡大/フィルター設定、印刷操作までの手順を記録してください。ROM/BIOS/セーブや個人の印刷画像は添付しないでください。

拡大表示中に短時間の黒画面が出るとの報告はあり、原因も修正も確認できていません。発生時は拡大とフィルター、表示画面、ボーダー、早送りの状態、およびリセットせずに画面が戻るかを記録してください。`VIDEO_TRACE=1`診断DSビルドは候補`a0846aae`でビルドとバイナリ検査を通過しましたが、通常版には含まれず、実機では未起動です。**Debug → Video Trace Dump**は現在のフォルダーに、新規の`gameyob_video_trace_00.csv`～`gameyob_video_trace_99.csv`を最初に使える名前で最大256件出力します。メニューを開くと記録を一時停止し、閉じると再開するため、メニューを開くまでの約0.2秒ほどの履歴しか残りません。ちらつき後すぐメニューを開いてください。症状がそれより前に発生した場合、イベントがないことは原因の否定になりません。ROM/セーブデータは送らないでください。ちらつき修正の検証完了とはしていません。提供された現在の設定スナップショットではGB Printer・拡大・フィルターがOn、SGB BordersとVblank待機がOff、HblankとWindowがOnです。ユーザーによればSGB Borders Offは以前の速度低下への回避策で、低下時はOnだったとのことです。ただしCustom Borderの以前の設定は不明です。この情報もちらつきの原因を特定するものではありません。

## 8. サウンドとデバッグ

**サウンドチャンネル**でパルス1、パルス2、波形、ノイズを個別に切り替えます。**デバッグ → サウンド**は全体スイッチです。DS専用の**Vblank待機**、**Hblank**、**Window**、**サウンドタイミング修正**は互換性診断用なので通常は既定値を維持してください。**ROM情報**はマッパー・ROM・RAM、**バージョン情報**は正確なビルド版を表示します。

3DSネイティブ固有の音声診断は保存版の資料に残し、現在のDS/DSiリリース対象外とします。

## 9. ローカルリンクと無線リンク

### ローカルリンク

**リンク → ローカルリンク**は1台で2つのGame Boyを動かします。**フォーカス切替**で別インスタンスを操作します。開始時に無線セッションを終了し、2台目のセーブを一度だけ初期化します。現在は両方に同じROMを使用します。

### DS/DSi無線

**無線リンク**はローカルraw NiFiを使うためインターネットは不要です。2台でHost/Clientと同じリンク種類を選び、近くに置いてください。DS、DSi、3DSのDSモード版がこの方式を使用します。

3DSネイティブLANは保存した3DSX版とともに保留しています。`.nds`のraw NiFiルームへ直接接続することはできません。詳細は[`backup/3dsx/TODO.md`](../../backup/3dsx/TODO.md)を参照してください。

## 10. RTCとパッチROM

MBC3/HuC3時計はホストの経過時間を使い、MBC3の停止・日数キャリービットを維持し、SRAMの後ろへ時計データを保存します。外部RAMのないRTC専用カートリッジにも対応します。システム時計を過去へ戻した場合は、大きな時刻ジャンプではなく基準時刻を再設定します。

パッチROMは古いヘッダー値ではなく実ファイルサイズを優先します。2の累乗でない配置を安全にミラーし、標準128KiBまでのSRAMヘッダーを扱い、不完全な最終バンクは`0xFF`で読みます。MBC5のハードウェア上限は8MiBで、それを超えるROMや独自マッパーには個別実装が必要です。

## 11. トラブルシューティング

- 言語が変わらない場合は一度Englishを選び、目的言語を選び直して設定を保存します。CustomはUTF-8と変更していない英語キーを確認してください。
- エミュレーターがSD上のUnicode名をHomebrewへ渡す前に`?`へ置換した場合、GameYobは失われた文字を復元できません。エミュレーターを更新するか、`gameyobds.ini`へ`autoloadrom=/gb/韓国語ファイル名.gbc`のようなUTF-8絶対SDパスを指定してください。
- `gameyob_dsi.nds`はDSiモードを要求しますが、実際に許可するかはランチャー側で決まります。DSモードで起動された場合は`gameyob.nds`と同じ性能になることがあります。
- DS raw NiFiはインターネットを使いません。2台を近くに置き、Host/Clientとリンク種類を一致させてください。
- ハックが起動しない場合は**デバッグ → ROM情報**でマッパー、実サイズ、RAMヘッダーを確認します。MMM01の0x0B-0x0Dは対応済みで、0x15-0x17は仕様不明のままです。MBC7 EEPROM/傾きとHuC1バンク/IR選択には自動テストがありますが、MBC7/HuC実カートリッジ検証は未実施です。
- 不具合報告へROMやBIOSを添付せず、ROMのSHA-256、マッパー、機種、ビルド版、再現手順を記録してください。

## 12. v0.5.10の整備内容

両NDSファイルはDS+DSiのunit code `0x02`と同じプログラムを持ち、
`gameyob_dsi.nds`には`GYOB`のtitle IDがあります。実行モードはランチャーが決定します。
v0.5.10では状態形式8を維持し、共通部分の長さとWRAM/VRAMバンクを検査します。
破損した可変長データ全体の検証ではありません。バックアップを保管し、拒否された
旧状態ファイルは削除せず報告してください。旧ZIPを上書きせず、新しいリリースとして導入してください。

v0.5.10は、大きなメモリへ適用する前に状態形式1～8のtail全体を
構造検査し、実験的SGBホスト65C816のオペコード分岐範囲を256/256へ
拡張しました。これはcycle-accurate CPUの完成を意味しません。
cycle timing、IRQ/reference trace、SPC700/DSPは未完成です。
DS NiFiの不正・欠落・順序違いfragmentも拒否します。自動試験済みですが、
状態バックアップを継続し、実機無線やSGBホスト完成とは扱わないでください。

韓国語版ポケモン銀でGBA検出On時に機種警告が出て、Offでは起動するとのユーザー報告が
あります。暫定的にOffを使用してください。正確なROM・BIOS・サスペンド状態の再現は
未確認です。ROMパッチは推奨せず、修正済みや実機GBA非対応とは主張しません。
