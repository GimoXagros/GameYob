# GameYob v0.5.9-ko 사용자 가이드 (한국어)

## 1. 빌드 선택

- `gameyob.nds`: DS, DS Lite, 플래시카드 및 Nintendo 3DS의 DS 모드에 권장합니다.
- `gameyob_dsi.nds`: DSi 모드를 명시적으로 실행하는 런처에서만 사용합니다. 에뮬레이터 본체는 일반 NDS판과 같으며 더 높은 성능을 보장하지 않습니다.
- Nintendo 3DS에서는 `gameyob.nds`를 DS 모드로 사용할 수 있습니다. 실험적인 네이티브 3DSX판은 이번 릴리스에 포함하지 않고 [`backup/3dsx`](../../backup/3dsx)에만 보존합니다.

ROM과 BIOS는 포함하지 않습니다. 합법적으로 준비한 `.gb`, `.gbc`, `.gbs` 파일을 SD 카드에 복사한 뒤 GameYob에서 선택하십시오. 콘솔 빌드는 SD 루트에 `gameyobds.ini`를 생성하므로 쓰기 가능한 상태여야 합니다.

## 2. 조작과 메뉴

기본 DS 계열 조작은 방향키, A/B, Start, Select를 그대로 사용합니다. 기본 DS 매핑에서는 R로 메뉴를 열고 L로 빨리 감습니다. **설정 → 버튼 매핑**에서 메뉴, 메뉴/일시정지, 저장, 연사, 빨리 감기, 리셋, 로컬 링크 포커스 교체를 포함한 기능을 변경할 수 있습니다. 화면 배율 동작은 현재 DS/DSi판에서만 유효합니다.

**화면 → 터치 메뉴**는 기본적으로 켜져 있습니다. 켜진 동안 메뉴와 ROM/파일 선택기는 저장된 **게임 화면** 값을 바꾸지 않고 실제 터치 가능한 아래 화면에 임시로 표시됩니다. 다른 행을 처음 누르면 선택만 하고, 선택된 실행 항목을 다시 누르면 실행합니다. 선택된 값 항목은 왼쪽/오른쪽 영역을 눌러 이전/다음 값으로 바꿉니다. 제목 줄의 왼쪽/오른쪽은 메뉴 분류 이동, 가운데는 메뉴 닫기입니다. 파일 선택기도 처음 터치로 선택하고 다시 터치해 열며, 화살표 영역은 스크롤하고 아래 종료 행은 Y와 같습니다. 기존 물리 버튼은 그대로 사용할 수 있습니다. 게임 중 설정 가능한 **Touch** 버튼 매핑은 터치 메뉴와 별개이며 UI 밖에서 그대로 작동합니다. Nintendo 3DS의 DS 모드에서 `gameyob.nds`를 실행할 때도 같습니다.

## 3. ROM 메뉴, 저장 및 일시중단

- **상태 슬롯**에서 0–9를 선택하고 **상태 저장/불러오기/삭제**를 사용합니다.
- **리셋**은 현재 카트리지를 재부팅하고 **일시중단**은 재개용 상태를 기록합니다.
- **종료**는 정상 저장하며 **저장하지 않고 종료**는 마지막 저장을 의도적으로 생략합니다. **런처로 종료**는 DS/3DS 런처로 돌아갑니다.
- 배터리 세이브는 `.sav`, 두 번째 로컬 Game Boy는 `.sa2`, 상태 파일은 `.ys0`–`.ys9`, 일시중단은 `.yss`를 사용합니다.
- DS판의 **자동 저장**은 백그라운드 SRAM 기록을 제어합니다. 전원이나 SD 카드를 제거하기 전에 정상 종료하십시오.

## 4. 설정과 언어

- **언어**에서 내장 영어, 일본어, 한국어 또는 사용자를 선택하면 즉시 반영됩니다.
- 사용자 선택 뒤 **언어 파일 선택**에서 UTF-8 INI, JSON, XML, YAML, YML 파일을 불러옵니다.
- **설정 저장**은 `gameyobds.ini`를 기록하고, 같은 위치에 파일이 없을 때만 영어 기본 `gameyob_language.ini`를 생성합니다. 기존 사용자 템플릿은 덮어쓰지 않습니다.
- **콘솔 출력**은 끄기, 시계, FPS+시계, 디버그 로그를 선택합니다.
- **GB 프린터**는 프린터 에뮬레이션을 켜며 출력물은 ROM 옆에 기록됩니다.
- DS 전용으로 **럼블 팩**, 지원 DSi의 **GB 카메라**(내부/외부), **자동 저장**이 있습니다.

외부 언어 파일 형식과 예시는 [언어 파일 안내](../../languages/README.md)를 참고하십시오.

## 5. 치트

ROM과 같은 위치에 같은 기본 이름을 사용합니다. `게임.gbc`의 치트 파일은 `게임.cht`입니다. UTF-8을 권장하며 기존 한국어 목록은 CP949도 읽습니다. 각 줄에는 Game Genie 코드(`AAA-BBB` 또는 `AAA-BBB-CCC`)나 8자리 GameShark 코드, 활성화 값, 표시 이름을 기록합니다. **설정 → 치트 관리**에서 켜고 끈 뒤 **설정 저장**으로 선택을 보존합니다.

## 6. 화면, 보더 및 Game Boy 모드

- **게임 화면**은 위/아래 화면을 고르고 **단일 화면**은 사용하지 않는 콘솔 화면을 숨깁니다.
- DS/DSi판에는 **화면 배율**과 **배율 필터**가 있습니다.
- **SGB 보더**는 대응 카트리지 보더를 표시합니다. **사용자 보더/보더 선택**은 BMP를 불러옵니다.
- DS/DSi판의 **GBC BIOS 선택**에서 정확히 0x900바이트인 `.bin` 파일을 지정할 수 있습니다. 선택한 뒤 게임을 초기화하거나 다시 불러오고 원하는 **GBC BIOS** 모드를 고릅니다. **설정 저장**을 실행하면 절대 경로가 `gameyobds.ini`의 `biosfile` 값으로 기록됩니다. 경로를 지정하지 않으면 현재 작업 폴더의 `gbc_bios.bin`을 찾는 기존 방식도 유지됩니다. BIOS는 선택 사항이며 배포물에 포함되지 않습니다.
- **GBC 모드**는 끄기, 필요할 때(CGB 전용 헤더 `0xC0`), 켜기(CGB 호환 헤더 `0x80`/`0xC0`)입니다. 켜기라도 흑백 전용 헤더를 강제 CGB로 실행하지는 않습니다. **SGB 모드**는 끄기, GBC 우선, SGB 우선입니다. **GBA 감지**는 부팅 시 기종 식별 플래그이며 속도 향상 옵션이 아닙니다. 모드를 바꾼 뒤 초기화하거나 ROM을 다시 불러오십시오.

## 7. 사운드와 디버그 옵션

**사운드 채널**에서 펄스 1, 펄스 2, 웨이브, 노이즈를 각각 켭니다. **디버그 → 사운드**는 전체 스위치입니다. DS 전용 **Vblank 대기**, **Hblank**, **Window**, **사운드 타이밍 수정**은 호환성 진단용이므로 보통 기본값을 유지하십시오. **ROM 정보**는 매퍼·ROM·RAM 정보를, **버전 정보**는 정확한 빌드 리비전을 표시합니다.

네이티브 3DS 전용 사운드 진단은 백업 자료에 남기며 현재 DS/DSi 릴리스 대상에서는 제외합니다.

## 8. 로컬 및 무선 링크

### 로컬 링크

**링크 → 로컬 링크**는 한 기기에서 Game Boy 두 대를 실행합니다. **포커스 교체**로 다른 인스턴스를 조작합니다. 시작할 때 활성 무선 세션을 닫고 두 번째 세이브를 한 번만 초기화합니다. 현재 로컬 링크는 두 인스턴스에 같은 ROM을 사용합니다.

### DS/DSi 무선

**무선 링크**는 로컬 raw NiFi를 사용하므로 인터넷이 필요하지 않습니다. 두 기기에서 호스트/클라이언트와 같은 링크 종류를 선택하고 가까이 두십시오. DS, DSi, 3DS DS 모드판이 이 백엔드를 사용합니다.

네이티브 3DS LAN은 백업한 3DSX판과 함께 보류합니다. `.nds` raw NiFi 방에는 직접 연결할 수 없습니다. 상세 작업은 [`backup/3dsx/TODO.md`](../../backup/3dsx/TODO.md)에 정리했습니다.

## 9. RTC와 패치 ROM

MBC3 및 HuC3 시계는 호스트 경과 시간을 사용하고 MBC3 정지·날짜 캐리 비트를 보존하며 SRAM 뒤에 시계 정보를 저장합니다. 외부 RAM이 없는 RTC 전용 카트리지도 지원합니다. 시스템 시계를 과거로 바꾸면 큰 시간 점프 대신 기준 시각을 다시 잡습니다.

패치 ROM은 오래된 헤더 크기 값보다 실제 파일 크기를 우선합니다. 2의 거듭제곱이 아닌 배치는 안전하게 미러링하고, 표준 128KiB까지의 SRAM 헤더를 지원하며, 불완전한 마지막 뱅크는 `0xFF`로 읽습니다. 하드웨어 MBC5 한계는 8MiB이며 그보다 큰 ROM이나 사용자 매퍼는 별도 구현이 필요합니다.

## 10. 문제 해결

- 언어가 바뀌지 않으면 영어를 한 번 선택한 뒤 목표 언어를 다시 선택하고 설정을 저장하십시오. 사용자 파일은 UTF-8과 변경하지 않은 영어 키를 확인합니다.
- 에뮬레이터가 SD 폴더의 유니코드 파일명을 홈브루에 넘기기 전에 `?`로 바꾸면 GameYob에서 잃어버린 문자를 복원할 수 없습니다. 에뮬레이터를 업데이트하거나 `gameyobds.ini`에 `autoloadrom=/gb/한글 파일명.gbc`처럼 UTF-8 절대 SD 경로를 지정하십시오.
- `gameyob_dsi.nds`는 DSi 모드를 요청하지만 실제 허용 여부는 런처가 결정합니다. DS 모드로 실행되면 `gameyob.nds`와 성능이 같을 수 있습니다.
- DS raw NiFi는 인터넷을 사용하지 않습니다. 두 기기를 가까이 두고 호스트/클라이언트 및 링크 종류를 동일하게 설정하십시오.
- 핵이 실행되지 않으면 **디버그 → ROM 정보**에서 매퍼, 실제 크기, RAM 헤더를 확인합니다. MMM01 0x0B-0x0D는 지원하며 기존 0x15-0x17은 사양 미상으로 남습니다. MBC7 EEPROM·기울기 및 HuC1 뱅킹·IR 선택은 자동 시험이 있지만 MBC7/HuC 실물 카트리지 검증은 아직 필요합니다.
- 버그 보고에 ROM이나 BIOS를 첨부하지 말고 ROM SHA-256, 매퍼, 플랫폼, 빌드 리비전과 재현 절차를 기록하십시오.

## 11. 미배포 정비 사항

두 NDS 파일은 DS+DSi unit code `0x02`와 동일한 프로그램을 가지며
`gameyob_dsi.nds`에는 `GYOB` 제목 ID가 있습니다. 실제 모드는 런처가 결정합니다.
v0.5.9 이후 정비는 상태 버전 8을 유지하면서 공통 구간 길이와 WRAM/VRAM 뱅크
검사를 추가합니다. 손상된 가변 상태 데이터 전체를 검증하는 것은 아닙니다.
백업을 보관하고, 거부된 이전 상태 파일은 삭제하지 말고 보고하십시오.
공개된 v0.5.9 ZIP은 이 정비 소스로 교체하지 않았습니다.

현재 미배포 브랜치는 대형 메모리를 적용하기 전에 상태 형식 1~8의 tail 전체를
구조적으로 선검증하고, 실험적 SGB 호스트 65C816 opcode 분기 범위를
256/256으로 확대했습니다. 이는 사이클 정확도까지 완성했다는 뜻이 아닙니다.
사이클 타이밍·IRQ/참조 trace·SPC700/DSP는 아직 미완성입니다. DS NiFi의
잘못된·누락된·순서가 바뀐 조각도 거부합니다.
자동 시험 결과이며, 상태 백업을 유지하고 실기 무선 및 SGB 호스트 완성
검증으로 간주하지 마십시오.

한국어판 포켓몬 은에서 GBA 감지 On이면 기종 경고가 나오고 Off이면 정상 실행된다는
사용자 보고가 있습니다. 우선 Off로 사용하며 정확한 ROM·BIOS·일시중단 상태 재현은
미확인입니다. ROM 패치를 권하지 않으며 해결 완료나 실제 GBA 비호환으로 주장하지 않습니다.
