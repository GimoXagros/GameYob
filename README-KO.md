# GameYob v0.5.2-ko.1

Stewmath/GameYob v0.5.2 안정판에 현대 한국어 파일 시스템 지원을 보강한
비공식 빌드다.

## 적용 내용

- FAT 긴 파일명 변환을 UTF-8 로케일로 초기화하여 한글 파일/폴더를 열 수 있음
- 파일 선택기에서 완성형 한글 11,172자와 현대 자모 표시
- UTF-8 및 CP949(Windows ANSI) 치트명 표시
- 한글 ROM명에 연결되는 `.sav`, `.cht`, `.yss`, `.ys0`~`.ys9`,
  프린터 BMP 파일의 읽기/쓰기 경로 확장
- UTF-8/CP949 문자열을 중간 바이트에서 잘라 손상시키지 않음
- 확장자가 없는 디렉터리 항목을 만났을 때 발생하던 잘못된 포인터 접근 수정
- 치트명에 `%`가 있을 때 포맷 문자열로 오인하던 문제 수정
- UTF-8 BOM이 붙은 치트 파일 지원

에뮬레이터 메뉴 자체의 한국어 번역은 포함하지 않는다. 파일명, 폴더명,
세이브·스테이트·프린터 파일 경로와 치트 목록의 현대 한국어 표시를 지원한다.

## 설치

- 일반 DS/DS Lite, 3DS의 DS 모드 및 대부분의 플래시카드:
  `gameyob-v0.5.2-ko.1.nds`
- DSi 모드 실행을 명시적으로 지원하는 런처:
  `gameyob-v0.5.2-ko.1-dsi.nds`

사용 중인 플래시카드의 DLDI 자동 패치 기능이 켜져 있어야 한다.
기존 GameYob 설정과 세이브 형식은 그대로 사용한다.
3DS에서 일반 DS 모드로 실행할 때는 일반판이 가장 호환성이 높다. DSi판은
런처가 DSi 모드로 실행할 때만 의미가 있으며, 이 에뮬레이터에서 눈에 띄는
성능 향상을 보장하지 않는다.

치트 파일은 ROM과 같은 경로에 같은 기본 이름으로 둔다.
예를 들어 `포켓몬 크리스탈.gbc`의 치트 파일은
`포켓몬 크리스탈.cht`다. UTF-8(권장) 또는 CP949로 저장할 수 있다.
